# D09 — Categories: one shared predefined set at the start; per-user customisation later
- Date, owner: 2026-10-22, Paweł Wójcik (founder)
- Context and the options weighed: Asked whether "specify categories" means one list for everyone or a list each user defines. Founder: "the same predefined set for everyone on the biginning. Customizable by users, independent for them".
- Decision and why: Start with one shared predefined set, assigned automatically. Later, each user can customise their own categories independently of other users. The timing of customisation (inside or after the pilot) was not stated; the brief places it under Later pending the founder's confirmation.
- Consequences, and what would make us revisit it: The data model must allow per-user category sets later. Exact labels remain open.
