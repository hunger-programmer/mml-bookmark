# Initial concept for a bookmark portal

Design an initial concept for a bookmark portal. Use case: I would love to have a place where I can easily store bookmarks and links to the recipies, movies, music and interesting things found in internet. AI will be used for categorization + content enhancement. Inpiration might be raindrop.io. Treat raindrop as a functional and UX benchmark; do not copy its visual identity, content or code.

## Expected outputs

Prepare:

1. A list of system users and their needs.
2. The main use cases and complete user flows.
3. A screen and navigation map.
4. For each screen:
    - purpose,
    - available features,
    - UI components,
    - loading, empty, error and success states,
    - validation,
    - related API endpoints.
5. Clickable mockups in HTML/CSS/TypeScript covering all key paths.

Package the result as a ZIP file so I can download it and place them into .ai/mockups/functionality folder.
